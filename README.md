### :art: "Artist's Portfolio 2.0"

---

#### About project :
- __Artist's Portfolio 2.0__ — a redesigned and rebuilt version of an artist's personal portfolio website.
- The project features a modern frontend, improved UI/UX, and enhanced functionality for browsing and filtering artworks.
- The website provides a responsive multilingual interface for presenting and exploring the artist's works.

#### Technologies and Tools :
__Backend :__
- Python
- Django

__Frontend :__
- JavaScript
- Svelte
- HTML
- CSS
- TailwindCSS

__Database :__
- PostgreSQL

__Tools :__
- Git
- GitHub

__Features :__
- Modern and responsive UI/UX optimized for desktop, tablet, and mobile devices.
- Multilingual interface.
- Artwork filtering by year and technique.
- Dynamic artwork categories.
- Detailed artwork presentation.
- Optimized image presentation and navigation.
- Content management through Django Admin.
